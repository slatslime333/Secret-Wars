# Secret Wars

A mobile-first 2D action game prototype built with Phaser, TypeScript, and Vite.

## Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run typecheck
npm run build
```

## Current prototype

The game currently includes the title/home flow and a mobile-first test arena. Enter the
match with **Play**, then use the left joystick to move and the right joystick to aim and
attack. Dash and Block sit above the attack joystick.

See [the combat prototype notes](docs/combat-prototype.md) for Ninja's baseline stats,
implemented controls, feedback rules, and the future animation/state roadmap.
